# 📢 Marketing Performance Analysis

> A marketing analytics project evaluating customer acquisition, user behavior, lifetime value, and marketing ROI to support data-driven investment decisions using Python.

---

# 📖 Project Overview

Understanding the effectiveness of marketing investments is essential for sustainable business growth. This project analyzes user acquisition, purchasing behavior, customer lifetime value, and marketing costs to evaluate campaign performance and identify opportunities to optimize marketing spend.

Using website visits, customer orders, and advertising cost data, the analysis measures customer acquisition efficiency, revenue generation, and return on investment to support strategic marketing decisions.

---

# 📂 Dataset

The project uses three datasets containing information about:

### Website Visits

- User ID
- Device Type
- Session Start
- Session End
- Traffic Source

### Customer Orders

- User ID
- Purchase Date
- Revenue

### Marketing Costs

- Advertising Source
- Date
- Marketing Cost

> **Note:** The datasets included in this repository are provided for educational and portfolio purposes.
